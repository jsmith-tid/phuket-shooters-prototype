# Tour-operator launch checks

This register concerns the English, Thai and Simplified Chinese operator pages. On the configured Cloudflare prototype, the group form can send an allowlisted request and customer receipt; on GitHub Pages it previews details. Neither action reserves or confirms a booking. Business owners below are proposed roles, not assigned people.
