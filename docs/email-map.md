# Customer email map

The customer receipt for both individual and group enquiries uses `public/assets/images/range_map.png`, the annotated map supplied for this project. The 1100 × 681 PNG marks Phuket Shooters Shooting Range and shows nearby roads and landmarks in Chalong, Phuket. It is displayed at up to 552 pixels wide in the email.

The image opens a pinned OpenStreetMap page. The email also gives the postal address and separate Apple Maps and Google Maps directions links using those coordinates. Check the marker, entrance and direction coordinates with the business before public release, especially for coach arrivals.

Linked attribution `© OpenStreetMap contributors · ODbL` sits directly below the image in the email. Keep it paired with the map if the layout changes. The image is hosted as a first-party site asset rather than requesting community map tiles each time a recipient opens a message. The text address and navigation links remain usable when images are blocked by an email client.
